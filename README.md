# I Know… You Don't — Thai online prototype

เกมจับกฎลับแบบออนไลน์หลายเครื่อง (ต้นแบบที่สร้างใหม่โดยได้รับแรงบันดาลใจจากแนวเกม ไม่ใช่สำเนาการ์ด/งานศิลป์/กติกาที่มีลิขสิทธิ์ของเกมต้นฉบับ)

## สิ่งที่มี
- ห้องออนไลน์พร้อมรหัสเชิญ 6 ตัว
- รองรับ 2–8 คน
- การ์ด 80 ใบ (4 สี × 4 รูปทรง × 5 เลข)
- กฎลับ 16 แบบ
- ลงไพ่แล้วระบบตอบว่าผ่าน/ไม่ผ่าน
- ผู้เล่นที่ไพ่หมดได้ทายกฎ
- บันทึกเหตุการณ์และสถานะผู้เล่นแบบเรียลไทม์

## วิธีรันบนเครื่อง
ต้องติดตั้ง Node.js 18 หรือใหม่กว่า

```bash
npm install
npm start
```
เปิด http://localhost:3000

## ทำให้เพื่อนเล่นจากคนละเครื่อง
1. นำโฟลเดอร์นี้ขึ้น GitHub
2. สร้าง Web Service บน Render (หรือโฮสต์ Node.js ที่รองรับ WebSocket)
3. ตั้ง Build Command: `npm install`
4. ตั้ง Start Command: `npm start`
5. เปิด URL ที่โฮสต์ได้ แล้วแชร์ URL และรหัสห้องให้เพื่อน

ใช้ WebSocket ผ่าน Socket.IO; ควรเลือกโฮสต์ที่รองรับ WebSocket และไม่ sleep ระหว่างเล่น

## กติกาในต้นแบบ
1. เจ้าของห้องสร้างห้องและส่งรหัสให้ผู้เล่น 1–7 คน
2. เมื่อมีอย่างน้อย 2 คน เจ้าของห้องกดเริ่ม ระบบสุ่มกฎลับและแจกไพ่คนละ 5 ใบ
3. ผู้เล่นผลัดกันเลือกไพ่ 1 ใบเพื่อทดสอบกฎ
4. ไพ่ที่ผ่านจะถูกทิ้ง ไพ่ที่ไม่ผ่านจะกลับเข้ามือ
5. เมื่อผู้เล่นคนหนึ่งไพ่หมด จะได้ทายกฎลับ โดยพิมพ์คำตอบให้ตรงกับชื่อกฎ
6. ทายถูกชนะ หากทายผิดจะได้รับไพ่เพิ่ม 2 ใบและเล่นต่อ
7. เจ้าของห้องเริ่มเกมใหม่ได้

## ข้อจำกัดของรุ่นต้นแบบ
- การเล่นเป็นแบบเลือกลงไพ่ได้ทันที ยังไม่มีระบบบังคับลำดับเทิร์น
- กฎลับถูกสุ่มจากชุด 16 กฎ; ผู้เล่นต้องพิมพ์ชื่อกฎตรงกับที่กำหนดเพื่อทายถูก
- สถานะห้องอยู่ในหน่วยความจำของเซิร์ฟเวอร์; หากรีสตาร์ตเซิร์ฟเวอร์ ห้องจะหาย
- ควรทดสอบการเชื่อมต่อและการเล่นพร้อมกันก่อนเปิดให้คนจำนวนมากใช้งาน
